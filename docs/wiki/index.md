## 推荐阅读路线

- 理解主链路：会话执行 → Agent/HITL → 根据任务选择业务专题。
- 调整供应商工具：外部工具 → 数据归属 → 行程规划 → 对应 Client 源码。
- 排查运行问题：会话执行中的当前状态 → 框架接入 → 对应 Run/Trace 与真实结果。
- 排查刷新后内容或统计缺失：[两表保存与读取](conversation.md#请求摘要与模型思考) → 数据与身份 → 框架执行摘要接入。
- 修改领域逻辑：对应业务专题 → 工程约定 → 应用服务、领域服务和已有测试。

## 已有验证入口与待核实范围

已有测试集中于 [服务测试目录](../../fons4ai-trip-agent-service/src/test/java/com/fons/cloud/ai/trip/)：对话应用、SSE、页面发布、审核修复校验、签证客户端与渲染器。当前协作仅将其作为阅读线索，未执行，也不推断覆盖了所有业务。

本地历史手工材料位于服务 `target/manual/` 中的天气、途牛、观测、取消及租约目录。它们是可被构建清理的环境产物，不是克隆仓库必然获得的证据；引用历史结果时应核对具体场景和产物，长期结论应连同适用边界保存在受影响专题或实际需要的开发记录中。

请求持久化的核心路径已通过最小验收：分析结果与实际 Master 思考刷新保留；子 Agent 业务工具与已知 Token 分段保存；两项审批一次提交后新旧 Run 分别统计；取消提示与未知用量可读。具体 Run、截图位置及尚未覆盖的拒绝、工具中取消、关闭观测等边界集中在 [请求结果验收记录](../development/features/20261019-request-summary/任务规划.md)，不以核心路径通过代替全部 AC。

当前需要持续关注的边界：取消提示已接入业务历史，普通请求在问题改写阶段取消及整页刷新已完成最小手工验收，其他取消场景尚未逐项验证；普通失败、超时提示尚未统一持久化；酒店未知计价口径不能用于确定住宿总价；完整规划与预订闭环不能由查询或类名推断；异常退出后的业务占用不自动接管。各项原因与源码位置在对应专题说明。
