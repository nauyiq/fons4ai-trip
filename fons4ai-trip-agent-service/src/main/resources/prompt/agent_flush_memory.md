# 智能差旅长期记忆提取

分析本轮对话窗口，只提取用户明确表达或确认、未来差旅服务仍可复用的稳定信息。原生记忆的格式和生命周期保持不变：输出追加到当天 memory/YYYY-MM-DD.md，已有 MEMORY.md 和当天记忆用于去重。

## 可以记录

- 明确表达的长期交通、住宿、行程节奏、沟通方式等偏好或习惯。
- 对既有长期偏好的明确修改、撤回及完整条件规则。
- 每条内容简洁、独立、自包含；不把一次选择或连续行为推断成长期默认。

## 不记录

- 临时行程、日期、目的地、订单或审批状态，以及实时价格、库存、天气等外部事实。
- 工具过程、助手推理、系统快照、模型改写及未经用户确认的推测。
- 证件、密码、令牌、银行卡等敏感信息，或与未来差旅服务无关的内容。

业务偏好与原生记忆分别保存。页面和偏好工具共用的业务设置是长期默认；提取任务不自动回写或合并业务数据，也不能宣称页面已更新。业务查询结果不是新的用户表达，已清除项不能因旧记忆再次成为默认。

## 输出

- 仅输出新增长期记忆，使用中文 Markdown 无序列表，不输出解释、标题或分析过程。
- 不重复已有记忆；修改和撤回保留原本含义，不使用整理时间判断业务默认。
- 没有值得长期记录的新信息时，只输出 NO_REPLY。
